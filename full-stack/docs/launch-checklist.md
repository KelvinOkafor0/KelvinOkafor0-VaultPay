# VaultPay launch checklist

## Regulated partner

[ ] Select CBN-regulated sponsor bank/PSP category appropriate to the exact product.
[ ] Contract for customer-account issuance/holding and settlement.
[ ] Contract card issuer/program manager/processor responsibilities.
[ ] Define chargeback/refund/dispute and fraud-loss allocation.
[ ] Define outage, incident, reconciliation, audit and termination/exit obligations.

## Identity and financial crime

[ ] KYC provider agreement.
[ ] CDD/EDD rules.
[ ] BVN/NIN and other required identity checks through approved channels.
[ ] Sanctions/PEP screening.
[ ] AML/CFT/CPF monitoring and suspicious-activity escalation/reporting.
[ ] Case-management and audit retention.

## Payments

[ ] Beneficiary name enquiry.
[ ] Transfer submission.
[ ] Status query.
[ ] Signed webhooks.
[ ] Retries and idempotency.
[ ] Reversals.
[ ] Provider reconciliation.
[ ] End-of-day settlement reconciliation.

## Cards

[ ] Issuer agreement.
[ ] Card product configuration.
[ ] Tokenization.
[ ] PIN/3DS/SCA strategy with issuer.
[ ] Freeze/unfreeze.
[ ] Replacement.
[ ] Card transaction webhooks.
[ ] PCI scope assessment.

## Security

[ ] Threat model.
[ ] Secure SDLC.
[ ] Independent penetration test.
[ ] Secrets manager.
[ ] KMS/HSM for keys.
[ ] MFA/step-up authentication.
[ ] Device/session controls.
[ ] SIEM/security monitoring.
[ ] Backup/restore test.
[ ] Disaster recovery exercise.

## Data protection

[ ] Privacy notice.
[ ] Data inventory.
[ ] Processor/vendor register.
[ ] Retention schedule.
[ ] Access/deletion/correction workflows.
[ ] Breach response process.

## Operational readiness

[ ] Customer support.
[ ] Complaints/dispute workflows.
[ ] Fraud operations.
[ ] AML/compliance operations.
[ ] Finance/reconciliation operations.
[ ] On-call rotation.
[ ] Incident management.
[ ] Production runbooks.
